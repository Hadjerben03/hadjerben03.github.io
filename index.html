Bone Age Detection with VGG16
Computer Science

A deep learning model that predicts a patient's bone age from hand X-ray images, built on a pre-trained VGG16 network combined with patient metadata (sex). Developed as my Bachelor's degree final project, with an iterative methodology of progressive fine-tuning and hyperparameter optimization across the full 12,564-image dataset.

My Role
Computer Science Student — Model Design & Training
Python TensorFlow / Keras VGG16 (Transfer Learning) Computer Vision Deep Learning
  • Preprocessed X-ray images (RGB conversion, normalization, resizing to 224x224) and integrated patient sex as an auxiliary input
  • Trained progressively: started with a frozen VGG16 base, then fine-tuned upper layers to adapt to medical imaging data
  • Optimized architecture and hyperparameters (batch size, learning rate, Dense layers with BatchNormalization and Dropout, EarlyStopping)
  • Reduced validation MAE from 31.8 to 11.02 through iterative experimentation on the full 12,564-image dataset
Simplified MPEG-4 Video Encoder Pipeline
Computer Science

A complete implementation of a simplified MPEG-4-like video encoder pipeline in Python, from raw image frames to a compressed binary file that can be decoded back into images. The project covers the five key stages of a video codec: pre-processing, intra-frame (I-frame) coding, inter-frame (P-frame) coding, entropy coding, and evaluation.

My Role
Computer Science Student
Python Video Compression DCT Motion Estimation Matplotlib
  • Implemented pre-processing with BGR → YCbCr color space conversion and chroma subsampling
  • Built intra-frame (I-frame) coding using DCT-based spatial compression
  • Built inter-frame (P-frame) coding with motion estimation and residual coding
  • Added lossless entropy coding for the final bitstream, plus PSNR-based quality evaluation and pipeline visualisation
  • Made GOP size, quantisation factor, and motion search window fully configurable
